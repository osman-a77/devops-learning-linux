# OverTheWire Bandit — Challenge Overview

## What is OverTheWire Bandit?

[OverTheWire](https://overthewire.org/) is a collection of wargames designed to help people learn and practice cybersecurity concepts through hands-on challenges.

**Bandit** is the introductory wargame and focuses primarily on learning the basics of working with Linux through the command line.

The challenges gradually introduce different Linux commands, file types, permissions, text-processing techniques, networking concepts, and other skills that are useful for cybersecurity.

## Objective

The objective of Bandit is to progress through a series of levels by finding the password required to access the next level.

Each level presents a different challenge. Solving the challenge provides the password needed to log into the next level.

The difficulty gradually increases, requiring the use of more commands and techniques as the levels progress.

## What I Am Learning

Throughout the challenge, I am using Bandit to develop practical skills in:

- Linux command-line navigation
- SSH
- File and directory management
- File permissions
- Finding files
- Reading and manipulating text
- Searching through files
- Linux processes
- Networking
- Encryption and encoding
- Shell commands and scripting
- Basic cybersecurity concepts
- Problem-solving and troubleshooting

## How This Repository Is Organized

Each Bandit level has its own folder containing a `README.md` file.

The documentation for each level follows the same structure:

### Challenge

A brief description of the problem that needs to be solved.

### Solution

The commands and steps used to solve the challenge.

### Brief Explanation

A short explanation of what the commands do and why they work.

### Password

An explanation of how the password for the next level is obtained.

> Passwords are intentionally not included in this repository.

### What I Learned

A summary of the main concepts, commands, or techniques learned from the level.

## Approach

For each level, I will first attempt to solve the challenge independently before documenting the solution.

The goal is not simply to complete each level, but to understand the commands and techniques being used.

When possible, I will also consider:

- Why a particular command works
- Whether there are alternative approaches
- What Linux concepts are involved
- How the technique could be useful outside of Bandit

## Goal

By completing and documenting the Bandit challenges, I aim to build a stronger foundation in Linux and command-line usage while developing the problem-solving skills needed for further cybersecurity study.

This repository serves as both a record of my progress and a reference for the techniques I learn throughout the challenge.
